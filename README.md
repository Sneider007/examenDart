Objetivo General
Desarrollar una aplicación CRUD en Dart desde consola, para gestionar un catálogo de productos
de una tienda, permitiendo crear, listar, actualizar y eliminar productos, utilizando:
● Listas
● Mapas
● Ciclos
● Estructuras switch-case
